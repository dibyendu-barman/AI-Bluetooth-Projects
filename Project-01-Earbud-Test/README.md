# 🎧 AI Bluetooth Earbuds Assistant

> **Project 01 — AI + Bluetooth + Speech-to-Text + Cloud AI + Text-to-Speech**

A practical AI Bluetooth Earbuds Assistant prototype built with **Python, Airdopes Joy, Whisper, Gemini API and Text-to-Speech**.

The project captures speech from Bluetooth earbuds, converts speech into text using Whisper, sends the text to Gemini for AI processing, and converts the AI response back into speech.
